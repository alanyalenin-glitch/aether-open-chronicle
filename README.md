# Aether Open Chronicle

Crea una red social moderna y minimalista llamada Aether. Debe tener un diseño elegante en modo oscuro por defecto. Incluye una pantalla de bienvenida limpia con inicio de sesión simulado, un feed cronológico principal (muro) donde los usuarios puedan publicar texto e imágenes sin algoritmos ocultos, una sección de perfiles de usuario personalizados y una pestaña de mensajes directos simulados. Utiliza un estilo visual limpio, tipografías modernas y componentes tipo Tailwind con transiciones suaves
